# MotionInsight assets

The original MotionInsight mark combines successive video frames, a target-object
trajectory, and a magnifying glass. Teal denotes motion evidence; the amber target
and interrupted trajectory denote a motion deficiency under inspection.

- `motioninsight-light.svg` / `motioninsight-dark.svg`: scalable README banners.
- `motioninsight-banner.png`: white-background banner for presentations.
- `motioninsight-icon.svg` / `motioninsight-icon.png`: standalone mark.
- `motion-failures.png`: Figure 1 from the repository's `paper.pdf`.
- `method-overview.png`: Figure 2 from the repository's `paper.pdf`.

The paper figures illustrate the paper's examples and conceptual method. Refer
to the code and `TRAINING.md` for details of the released checkpoint implementation.
